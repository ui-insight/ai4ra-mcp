# RFA Sheet

Fetches a chosen funding opportunity and lays it out on an RFA sheet: the record's facts, the announcement's requirements, the ceiling as a number, and the project rows from the user's context. Records keyed notes when it runs inside a workflow.

**Version:** 0.4.1 · **Category:** drafting · **Status:** experimental · **Output:** a spreadsheet sheet

## Inputs

An opportunity the user chose (finder number, grants.gov link or title) and any project context.

## Outputs

An RFA sheet, Field and Value columns.
