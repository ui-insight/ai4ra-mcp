# Work Plan

Lays out a project's activities and milestones on a Work plan sheet from a narrative's objectives and approach, with named leads, start months and durations in months.

**Version:** 0.1.0 · **Category:** drafting · **Status:** experimental · **Output:** a spreadsheet sheet

## Inputs

A Narrative sheet (or the objectives), the team, the project length.

## Outputs

A Work plan sheet with six columns, ready for the Gantt and budget skills.
