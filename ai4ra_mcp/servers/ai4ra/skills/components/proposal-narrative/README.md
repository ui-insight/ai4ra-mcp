# Proposal Narrative

Drafts a proposal narrative from an RFA sheet and the user's context onto a Narrative sheet, and in a finish pass replaces its timeline and budget placeholders with prose from the Work plan and Budget draft sheets.

**Version:** 0.1.0 · **Category:** drafting · **Status:** experimental · **Output:** a spreadsheet sheet

## Inputs

An RFA sheet and the project context; for the finish pass, the Work plan and Budget draft sheets.

## Outputs

A Narrative sheet, one paragraph per row under bold headings.
