# Budget Outline

Writes a plain first budget on a Budget outline sheet, one item per row with a quantity and a unit cost, sized to the announcement's amount; the sheet computes the years, the total and the share of the ceiling. Ships a template the pane lays down.

**Version:** 0.1.0 · **Status:** experimental

## Inputs

The team, the work plan, the project length and the ceiling.

## Outputs

A Budget outline sheet the NSF template is filled from.
