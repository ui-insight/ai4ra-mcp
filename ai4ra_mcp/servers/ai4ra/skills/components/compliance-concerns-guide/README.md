# Compliance Concerns Guide

A vocabulary for grouping: twenty concerns a statement about a sponsored project can raise, each a name and a description of what it covers and where it stops. It cites no regulation and no policy; which rule governs a statement is found from the statement by the skill of whichever server holds that source. Served by the `ai4ra_guide` tool (name `compliance-concerns-guide`) and as an MCP prompt (ai4ra-mcp #15).

Draft 0.1. The categories are the research office's to own and have not been reviewed by it: whether twenty is too fine, and whether "Allowability of costs" is too broad to stand alone, are open.
