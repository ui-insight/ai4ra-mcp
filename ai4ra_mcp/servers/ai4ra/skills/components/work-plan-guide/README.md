# Work Plan Guide

The judgment of the `work-plan` skill with the placement taken out: what a correct result is, in terms that name no client, so any MCP client can follow it and put the result where it likes. Served by the `ai4ra_guide` tool (name `work-plan-guide`) and as an MCP prompt. The `work-plan` skill remains beside it until its placement half moves to the client (mindrouter-365 #36).
