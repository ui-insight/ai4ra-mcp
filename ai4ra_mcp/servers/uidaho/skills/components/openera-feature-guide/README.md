# OpenERA Feature Guide

The facts of the University of Idaho's OpenERA feature-definition work, as the `feature-prd-interview` skill reads them: the OpenERA list and the `feature` tag, the Roadmap status block and the AI first pass with its Basis tags, the names of the pass and discrepancy subtasks and the markers inside a definition, the thirteen headings, the shape of an acceptance criterion, the data a definition never holds, the connected systems, the acceptance-criteria index task with its line forms and vocabulary, the Data Sensitivity field, and whose decision each thing is. Facts and reference only, in terms that name no client; the interview is the skill's. Served by `uidaho_guide` (name `openera-feature-guide`), as an MCP prompt and as a static file.

**Version:** 0.1.0 · **Category:** guide · **Status:** experimental

When the list, the index task or a subtask's name changes, this is the one file that changes.
