# Ask — Prompt

> **Purpose:** Put a question to the user and stop. The user's reply is the result.
> **Expected input:** The question, and what it is about, in the request.
> **Expected output:** The question, put to the user in a few lines; then the user's reply, which is what a caller receives.

---

## Prompt

Say in one line what this is about, then put the request's question to the user, plainly and completely, with any choices or assumptions the request names. The request's facts (a tab name, an opportunity, a list) are stated in the question in their own words, not described: "The export is on the tab FRIGITD, as given. Is that right?", never "Show the tab taken and ask whether it is right". Ask nothing the request does not ask. Call no tools and add nothing else. End your turn and wait; the reply is the result.

---

## Quality Standards

1. **The request's question, nothing more.**
2. **No tools, no work of your own.**
